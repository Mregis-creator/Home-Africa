# 🧪 Quick Test Guide - Rich Response Model

## 🚀 Quick Start Testing

### **1. Open Your Website**
- Open `index.html` in your browser
- Or use Live Server extension

### **2. Open Chatbot**
- Look for **Rejo AI** sticker (headphones icon) near footer
- Click it to open chatbot

### **3. Test These Queries**

#### **Test 1: Greeting**
```
Type: "Hello"
Expected: Quick reply buttons + suggestions
```

#### **Test 2: Search**
```
Type: "Show me apartments"
Expected: Rich listing cards with images + quick replies
```

#### **Test 3: Availability**
```
Type: "Are houses available?"
Expected: Quick replies + action button + suggestions
```

#### **Test 4: Price**
```
Type: "What's the price range?"
Expected: Quick replies + filter action button
```

#### **Test 5: Location**
```
Type: "Where are properties located?"
Expected: Location quick replies + suggestions
```

#### **Test 6: How-To**
```
Type: "How do I book a viewing?"
Expected: Action buttons + suggestions
```

### **4. Test Interactions**

✅ **Click Quick Replies** - Should send message automatically
✅ **Click Action Buttons** - Should navigate to pages
✅ **Click Listing Cards** - Should go to detail page
✅ **Click Suggestions** - Should send question

### **5. Visual Checks**

✅ Listing cards show images
✅ Buttons have hover effects
✅ Everything is clickable
✅ Mobile responsive

---

## 🎯 Success Indicators

✅ **Working correctly if:**
- Cards display with images
- Buttons appear and work
- Navigation works
- No console errors
- Mobile friendly

---

## 🐛 If Something Doesn't Work

1. **Open Browser Console** (F12)
2. **Check for Errors** (red text)
3. **Verify:**
   - Supabase connection
   - Scripts loaded
   - No JavaScript errors
