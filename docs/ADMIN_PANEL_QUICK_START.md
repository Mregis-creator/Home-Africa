# Admin Panel Quick Start Guide

## ✅ You're Now Logged In!

As a **Super Admin**, you have access to everything:

### 🎯 What You Can Do:

1. **Dashboard Tab** (Default)
   - View platform-wide statistics
   - See all listings, merchants, users
   - Storage usage

2. **Listings Tab**
   - View ALL listings from ALL merchants
   - Edit any listing
   - Delete any listing
   - Toggle listing status (active/inactive)

3. **Users Tab**
   - View all registered users/merchants
   - Delete users (with their listings)

4. **Merchants Tab**
   - View all merchants
   - Verify/unverify merchants
   - Delete merchants

5. **Files Tab**
   - View all uploaded images/files
   - Delete files
   - See file sizes and locations

6. **Analytics Tab**
   - View platform analytics
   - Charts and statistics

## 🔍 Quick Actions

### Search Listings
- Use the search box in Listings tab to find specific listings

### Edit a Listing
- Click the pencil icon (✏️) next to any listing
- Modify title, price, status
- Save changes

### Delete a Listing
- Click the trash icon (🗑️) next to any listing
- Confirm deletion
- Images will also be deleted from storage

### Verify a Merchant
- Go to Merchants tab
- Click the checkmark icon (✓) to verify
- Click X to unverify

## 🚪 Logout

Click the "Logout" button in the navbar to sign out.

## 🔄 Auto-Login

Since you're using dev mode, you'll stay logged in until you:
- Click Logout
- Clear browser storage
- Set `DEV_MODE = false`
