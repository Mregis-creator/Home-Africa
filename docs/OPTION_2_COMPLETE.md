5. See unread badges for new messages
6. Start new conversations

### Features:
- **Threads List:** Shows all conversations with preview
- **Chat Area:** Displays messages in conversation
- **Send Messages:** Type and send instantly
- **Unread Counts:** Badge shows unread messages
- **Auto-updates:** Checks for new messages every 5 seconds
