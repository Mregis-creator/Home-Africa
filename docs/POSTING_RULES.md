# 📝 Posting Rules & Features

## 🎯 User Types & Posting Permissions

### **Regular Users (Non-Merchants)**
- ✅ **Can only post:** "Want to Buy" posts (product type)
- ✅ **Prompt:** "What do you want to buy?"
- ✅ **Purpose:** Express what they're looking to purchase
- ✅ **Visibility:** Always Public (so merchants can see and respond)
- ✅ **Features:**
  - Budget range (min/max)
  - Preferred location
  - Detailed requirements
  - Images

### **Merchants**
- ✅ **Can post:** All post types
  - Product Listings
  - Articles
  - Questions
  - Market Insights
  - Updates
  - Announcements
- ✅ **Prompt:** "Create New Post"
- ✅ **Visibility Options:** Public, Connections Only, Private
- ✅ **Features:**
  - Link to existing listings
  - All post types
  - Full visibility control

---

## 🔄 Post Flow

### For Regular Users:
1. Click "Create Post"
2. See: **"What do you want to buy?"**
3. Fill in:
   - What they want (title)
   - Details/requirements
   - Budget (optional)
   - Preferred location (optional)
   - Category (apartments, cars, land)
   - Images (optional)
4. Post is **always Public** so merchants can see it
5. Merchants can comment/DM to help

### For Merchants:
1. Click "Create Post"
2. See: **"Create New Post"**
3. Choose post type
4. Fill in relevant details
5. Choose visibility
6. Publish

---

## 💡 Benefits

- **Buyers:** Easy way to express needs, merchants can find them
- **Merchants:** Can see buyer needs, create targeted listings, build relationships
- **Platform:** More engagement, better matching, community building
