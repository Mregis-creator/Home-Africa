EmailJS Version (No Domain Required)

⚠️ Setup Required: You need to configure EmailJS before testing.

📋 Setup Steps (One-time):

  1. Go to emailjs.com and sign up (free)
  2. Add an Email Service (Gmail, Outlook, or SMTP)
  3. Create ONE email template with these variables: {{to_email}}, {{to_name}}, {{subject}}, {{html_content}}
  4. In the template body, paste: {{html_content}} (this renders the full HTML email)
  5. Copy your Service ID, Template ID, and Public Key into js/email-service-emailjs.js
  6. Reload this page and test all 4 email types!

💡 Free tier: 200 emails/month. One template handles Welcome, Lead, Payment, and Password Reset emails!
